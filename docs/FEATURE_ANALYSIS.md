# Feature Analysis

The archived feature-analysis configuration is available at:

`reported_results/feature_analysis/physical_context_selection_config.json`

This file preserves information from the exploratory feature-analysis stage and should not be confused with the model-stage configuration.

The file `configs/physinput_model_config.json` defines the shared predictor channels, four derived diagnostic inputs, and the hierarchical PhysInput configurations used by the public modular implementation.

Historical PCA and other exploratory analysis outputs are retained for provenance, although not all of them are included in the revised manuscript.

The existence of these archived outputs does not establish complete behavioral equivalence between the public modular workflow and the original formal training pipeline.
