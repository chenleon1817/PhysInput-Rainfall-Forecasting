# Feature Analysis

`reported_results/feature_analysis/physical_context_selection_config.json` is the original feature-analysis artifact. It is not present in this workspace and was not reconstructed. `configs/physinput_model_config.json` is the model-ready adaptation: it retains the eleven shared inputs and screened scientific basis, adds the four derived diagnostics needed by model construction, defines Lite, Adv3, Conv3, and All4, and omits analysis-only tables, arrays, paths, and bootstrap details. It does not redefine feature analysis or alter its numerical result.
