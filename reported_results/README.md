# Reported Results

This directory contains lightweight artifacts generated by the original formal
experiment and used to support the manuscript results.

Archived result files may retain legacy experiment-group names and result keys
from the original training implementation. These names are preserved as part
of the original run record.

Included artifacts:

- feature-analysis tables and figures;
- continuous and event metrics;
- PhysInput ablation results;
- event-count and prediction-intensity diagnostics;
- sample-balance metadata; and
- final manuscript figures.

Large artifacts intentionally omitted:

- complete annual ERA5 files;
- model checkpoints;
- full long-form prediction tables;
- `all_experiments_summary.json`;
- `group_summary.json`; and
- training logs.

The omitted model outputs can be regenerated with the scripts in `scripts/`
when the complete input data are available.
